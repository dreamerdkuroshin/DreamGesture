# Download & Install DreamGesture

This page explains how to download and install DreamGesture on any device.

---

## Option 1: Download from GitHub Releases (Recommended)

1. Go to **[github.com/dreamerdkuroshin/DreamGesture/releases](https://github.com/dreamerdkuroshin/DreamGesture/releases)**
2. Click on the latest release (e.g., "v1.0.0")
3. Download the file for your platform:
   - Android → `DreamGesture-android.apk`
   - Windows → `DreamGesture-windows.msi`
   - macOS → `DreamGesture-macos.dmg`
   - Linux → `DreamGesture-linux.AppImage`

---

## Option 2: Download as ZIP

1. Go to **[github.com/dreamerdkuroshin/DreamGesture](https://github.com/dreamerdkuroshin/DreamGesture)**
2. Click the green **"Code"** button
3. Click **"Download ZIP"**
4. Extract the ZIP file
5. Open the folder for your platform:
   - `dist/android/` → APK file
   - `dist/windows/` → MSI file
   - `dist/macos/` → DMG file
   - `dist/linux/` → AppImage file

---

## Platform-Specific Instructions

### Android (APK)

1. Download `DreamGesture-android.apk`
2. Open file manager, find the APK
3. Tap to install
4. Enable "Unknown sources" if prompted
5. Grant Camera, Storage, Location permissions

### Windows (MSI)

1. Download `DreamGesture-windows.msi`
2. Double-click to run
3. If SmartScreen warning: "More info" → "Run anyway"
4. Follow installer wizard
5. Launch from Start Menu

### macOS (DMG)

1. Download `DreamGesture-macos.dmg`
2. Double-click to open
3. Drag to Applications folder
4. Right-click → Open (first time only)

### Linux (AppImage)

1. Download `DreamGesture-linux.AppImage`
2. Right-click → Properties → Permissions → "Allow executing"
3. Double-click to run

**Or terminal:**
```bash
chmod +x DreamGesture*.AppImage
./DreamGesture*.AppImage
```
